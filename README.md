Token launch radar: reads a frozen DefiLlama snapshot of 758 protocols and ranks every pre-token protocol that could still launch one by implied value (TVL × category multiple × growth × maturity). Top board: Steakhouse Financial $442.8M, Sentora Curator $414.7M, Gauntlet $263.7M. Built by an AI agent for make.fun's "best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
